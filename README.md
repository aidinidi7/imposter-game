# Imposter Game

Ein schlichtes Imposter-Wortspiel fuer 3 bis 10 Leute am selben Tisch. Jeder nutzt sein eigenes Handy, ohne Server und ohne Anmeldung.

## So wird gespielt

1. Alle oeffnen die Seite und geben denselben Raumcode und die Spieleranzahl ein.
2. Jeder waehlt eine eigene Spielernummer (1, 2, 3, ...), keine doppelt.
3. Jeder deckt seine Rolle auf: Alle sehen dasselbe Wort, nur der Imposter nicht.
4. Reihum sagt jeder ein passendes Wort. Der Imposter versucht, nicht aufzufallen.
5. Am Ende muendlich abstimmen, dann "Naechste Runde".

## Lokal starten

Im Projektordner:

```bash
python serve.py
```

Dann im Browser `http://localhost:8080` öffnen. Beenden mit `Strg + C` im Terminal.
